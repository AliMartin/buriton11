# Buriton POC handover bundle — read before use

This archive preserves the completed local Drupal 9 → 10 → 11 technical POC
source and documentation as of 19 October 2026. Start with `docs/README.md` and
`docs/drupal11/poc-handover.md`. The tested lock is Drupal 11.4.10; all four core
requirements use `^11.4.10` for future compatible stable Drupal 11 updates.

This is **not a production deployment artifact or a data backup**. It excludes
SQL dumps, uploaded/private file trees, actual settings/credentials, generated
dependencies, TLS material, temporary data and previous private archives.
`sync/recaptcha.settings.yml` is included with its secret key cleared in this
archive copy only. Source the real key securely from the fresh live environment
before form testing. The included configuration records this POC's migration;
review/merge it against live configuration rather than importing it blindly.

Restore a fresh private database and complete file trees, create appropriate
local settings, then use Composer to rebuild dependencies from the tested lock.
The Composer-managed TB Mega Menu and Bootstrap5 custom paths are generated by
explicit installer rules and locked patches; their installed directories are
not bundled. The maintained Zircon and Buriton5 theme sources are bundled.

The inherited `.cpanel.yml` appears for source context only. Replace its blanket
copy task before any real deployment. Keep docs, developer tools, local settings
and private data out of public deployment artifacts; review root runtime
scaffolds/dotfiles and the host's access rules deliberately.

The adjacent archive `.sha256` verifies this complete bundle. The included
`docs/drupal11/evidence/2026-10-19-poc-closeout/source-manifest.json` hashes the
bundled source files after sanitisation; it excludes itself and the close-out
checksum manifest to avoid recursive hashes. Earlier evidence checksum files
retain their original snapshot scope, and dated documentation may describe
superseded states. No production deployment, source commit or workflow/browser
sign-off is implied by this source archive.
